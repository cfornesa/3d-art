# Plan: Mobile Layout for studio.php — Canvas + Config Panel Stacking

## Problem
In mobile view (≤768px), the configuration panel (`#dta-sidebar`) should be below the canvas (`#dta-canvas-region`), with both at 100% width.

## Reference
`css/data-app.css` lines 1016–1038 show the desired mobile behavior for studio.php:
- `#dta-main`: flex-direction column, height auto, overflow auto
- `#dta-canvas-region`: flex none, width 100%, height 60vh, min-height 300px
- `#dta-sidebar`: flex none, width 100%, max-width none, min-width 0, border-left none, border-top gold accent

## Missing CSS in app.css
`css/app.css` mobile section (lines 956–1015) lacks studio.php-specific rules. It ends at line 1015 without stacking rules for `#dta-main`, `#dta-canvas-region`, and `#dta-sidebar`.

## Proposed Change
Add to the existing `@media (max-width: 768px)` block in `css/app.css` (after line 1014):

```css
/* studio.php: sidebar stacks below canvas */
#dta-main {
  flex-direction: column;
  height: auto;
  overflow: auto;
}

#dta-canvas-region {
  flex: none;
  width: 100%;
  height: 60vh;
  min-height: 300px;
}

#dta-sidebar {
  flex: none;
  width: 100%;
  max-width: none;
  min-width: 0;
  border-left: none;
  border-top: 2px solid #c9922a;
}
```

## Assumption
The assumption is that the reference file's styling approach (60vh canvas height on mobile) is the intended behavior. An alternative would be to use `min-height` instead of fixed `60vh` for more flexible mobile handling.
