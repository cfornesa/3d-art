# Layer System Fix Plan — studio.php Figure Manager

## Problems Identified

### Problem 1: New figures added to bottom (layer 0)
**Location:** `src/figures/figure-base.js` line 53

**Root Cause:** New figures default to `layer: 0`. Since `_sortByLayer()` sorts ascending, new figures with layer 0 end up at the **bottom** of the visual stack (back).

**Assumption confirmed:** New figures should appear at the **top** of the layer stack (visually "in front").

---

### Problem 2: Up arrow moves layer DOWN, Down arrow moves layer UP
**Location:** `src/figures/figure-manager.js` lines 291-333

**Root Cause:** The swap targets are inverted:
- `moveUp` swaps with `index + 1` (element below) — moves figure visually **down**
- `moveDown` swaps with `index - 1` (element above) — moves figure visually **up**

Layer values after swap also don't match visual intent.

---

## Solution (Confirmed: 0 = bottom/back, higher = front)

### 1. Fix `createDefaultFigure` — new figures get max layer + 1
**File:** `src/figures/figure-manager.js` lines 116-122

In `createDefaultFigure`, compute highest existing layer and assign `layer: maxLayer + 1`:

```javascript
const maxLayer = this._figures.reduce((max, f) => Math.max(max, f.layer || 0), -1);
return window.DataToArt.FigureBase.create({
    type: libraryDefaults.type,
    name: 'Figure ' + (this._figures.length + 1),
    color: '#c9922a',
    library_data: libraryDefaults.library_data,
    layer: maxLayer + 1,
});
```

### 2. Fix `moveUp` — swap with element above (index - 1)
**File:** `src/figures/figure-manager.js` lines 291-309

"Moving up" should place the figure visually above (in front). Swap with `index - 1`:

```javascript
FigureManager.prototype.moveUp = function(figureId) {
    const index = this._findIndexById(figureId);
    if (index === -1 || index <= 0) return;
    
    const temp = this._figures[index];
    this._figures[index] = this._figures[index - 1];
    this._figures[index - 1] = temp;
    
    this._assignLayerIndices();
    this._updateUI();
    this._onChange({ action: 'reorder', figureId: figureId });
};
```

### 3. Fix `moveDown` — swap with element below (index + 1)
**File:** `src/figures/figure-manager.js` lines 315-333

"Moving down" should place the figure visually below (behind). Swap with `index + 1`:

```javascript
FigureManager.prototype.moveDown = function(figureId) {
    const index = this._findIndexById(figureId);
    if (index === -1 || index >= this._figures.length - 1) return;
    
    const temp = this._figures[index];
    this._figures[index] = this._figures[index + 1];
    this._figures[index + 1] = temp;
    
    this._assignLayerIndices();
    this._updateUI();
    this._onChange({ action: 'reorder', figureId: figureId });
};
```

### 4. Add `_assignLayerIndices` helper
**File:** `src/figures/figure-manager.js`

After reordering, assign layer values to match array indices (0 = bottom):

```javascript
FigureManager.prototype._assignLayerIndices = function() {
    for (let i = 0; i < this._figures.length; i++) {
        this._figures[i].layer = i;
    }
};
```

Call this after both `moveUp`, `moveDown`, and in `_sortByLayer` if needed.
