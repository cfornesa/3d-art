# Plan: Fix exhibit.php embed parameter behavior

## Problem Statement
When visiting `http://localhost:8000//exhibit.php?id=5&embed=true`, the user expects ONLY the `#dta-exhibit-visual` element (the canvas/artwork visual) to be visible, hiding header, details, embed section, and footer.

## Confirmed Approach: Option A - CSS hiding on regular page

### Implementation

1. **Detect embed=true**: In the PHP section at top of exhibit.php (line ~84), `$isEmbed` is already set when `embed=true` is passed.

2. **Pass embed flag to JavaScript**: Add `embed: true/false` to the `artwork` JavaScript object passed to inline script (line ~525).

3. **Apply CSS hiding when embed=true**: In the inline script's `initExhibit()` function, if `embed === true`, hide non-visual elements:
   - `#dta-exhibit-header`: `display: none`
   - `#dta-exhibit-details`: `display: none`
   - `#dta-exhibit-embed`: `display: none`
   - `#dta-exhibit-footer`: `display: none`
   - Keep `#dta-exhibit-hero` visible (contains the visual)

4. **Ensure #dta-exhibit-visual is visible**: Make sure the target element has explicit `display: block` when in embed mode.

### Assumption
The embed parameter is intended for visual-only display (gallery embedding use case) rather than the minimal iframe HTML that currently exists. This is consistent with "dta-exhibit-visual should be the only content visible."

### Files to Modify
- `exhibit.php`: Lines ~525 (add embed flag to JS), ~531-607 (add CSS hiding in initExhibit)
